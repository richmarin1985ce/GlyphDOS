THE CONCEPT

Classic text-mode game creation evolved beyond the 80×25 VGA screen. GlyphDOS uses a software canvas so you can build boards of different sizes, mix Unicode with DOS characters, and script interactive objects.

CREATE A GAME

  1. Choose Board Editor and paint terrain, overlays, or objects.
  2. Choose Glyph Studio to choose or draw characters.
  3. Select an object and edit its :touch script.
  4. Switch to Play to test your game.
  5. Export your world JSON; import to continue editing.

CONTROLS

WASD/arrows to move, E to interact, Space to shoot. In the editor, click/drag to paint and right-click to erase. Custom glyphs begin with @bank:slot.

LIMITS

Board maximum: 200×120; 128 boards/world; 500,000 cells/world; 4,096 authored bitmap glyphs/world. The current runtime uses one on-screen viewport of 60×25 tiles and a fixed-step ticker.

INTEROPERABILITY

This is an original engine inspired by ZZT and MegaZeux. Its scripting and JSON world file are not binary-compatible with .ZZT, .MZX, or Robotic programs.
